# UI系统开发文档

## 1. 系统概述
UI系统采用多层级架构，管理游戏中的所有界面元素。

## 2. UI层级架构
- UIRoot - UI根节点
- UIPageLayer - 页面层（主界面、背包等）
- UIPopupLayer - 弹窗层（对话框、确认框等）
- UITipsLayer - 提示层（飘字、通知等）

## 3. BaseWindow基类
- 窗口基类接口定义
- 显示/隐藏控制
- 层级管理
- 生命周期管理

## 4. UIManager管理器
- 窗口注册与注销
- 窗口显示/隐藏
- 窗口层级调整
- 窗口堆栈管理

## 5. 窗口创建流程
创建窗口 → 注册窗口 → 显示窗口 → 事件绑定 → 初始化完成

## 6. 窗口关闭流程
事件解绑 → 隐藏窗口 → 释放资源 → 注销窗口

## 7. 注意事项
- 层级顺序规范
- 内存管理
- 事件泄漏防护
- 多语言支持
