# 地图系统开发文档

## 1. 系统概述
地图系统负责游戏地图的加载、生成和管理，基于Tilemap实现2D网格地图，采用模块化的房间设计，支持程序化生成与人工编辑相结合。

## 2. 核心架构

### 2.1 房间系统架构
```
RoomSystem
├── RoomTemplate          - 房间模板（ScriptableObject）
├── RoomGraphGenerator     - 房间图生成器
├── RoomPlacer            - 房间放置器
├── MapGenerationConfig    - 地图生成配置
└── GeneratedMap         - 生成的地图数据
```

### 2.2 房间类型
| 类型 | 说明 | 数量要求 |
|------|------|---------|
| StartRoom | 起始房间 | 1个 |
| NormalRoom | 普通战斗房间 | 多个 |
| EliteRoom | 精英战斗房间 | 少量 |
| RestRoom | 休息/事件房间 | 少量 |
| ShopRoom | 商店房间 | 少量 |
| TreasureRoom | 宝箱房间 | 少量 |
| BossRoom | Boss房间 | 1个 |

## 3. 房间数据结构

### 3.1 RoomTemplate
```csharp
- roomId: 唯一标识
- roomType: 房间类型
- prefab: 房间预制体
- exits: 出口列表
- width/height: 尺寸
- difficulty: 难度等级
```

### 3.2 ExitData
```csharp
- exitId: 出口ID
- tilePosition: 瓦片坐标
- direction: 出口方向（上下左右）
- exitType: 出口类型（普通/锁门/隐藏）
- connectedExitId: 连接的出口ID
```

## 4. 地图生成算法

### 4.1 生成流程
```
1. 初始化随机种子
2. 创建起点房间和终点Boss房间
3. 规划多条主路径（连接起点和终点）
4. 在主路径上添加分支路径
5. 建立分支之间的横向连接，使不同路径连通
6. 在路径上插入特殊房间
7. 验证路径连通性
8. 计算房间物理位置
9. 生成走廊连接
```

### 4.2 分支算法
- 生成2-3条主路径，起点到终点
- 每条主路径长度：5-8个房间
- 不同主路径之间建立横向连接，确保所有路径互相连通
- 每3个房间可产生1-2个分支
- 特殊房间（精英、休息、商店、宝箱）按配置比例插入

## 5. UnityEditor房间编辑器

### 5.1 编辑器工具
| 工具 | 说明 |
|------|------|
| RoomEditorWindow | 主编辑器窗口 |
| TilePainter | 瓦片绘制器 |
| ExitEditor | 出口编辑器 |
| RoomPreviewWindow | 房间预览窗口 |
| MapTestWindow | 地图测试窗口 |

### 5.2 编辑器功能
- 工具栏：选择/放置瓦片/设置出口
- 画布：实时预览房间布局
- 属性面板：配置房间属性
- 出口列表：管理房间出口
- 预览窗口：浏览所有房间模板

## 6. 核心类

### 6.1 数据类
- `RoomTemplate` - 房间模板资源
- `MapGenerationConfig` - 生成配置
- `GeneratedMap` - 生成的地图
- `GeneratedRoom` - 生成的房间实例
- `RoomConnection` - 房间连接

### 6.2 管理器
- `MapModule` - 地图模块
- `MapManager` - 地图管理器
- `RoomGraphGenerator` - 房间图生成器
- `RoomPlacer` - 房间放置器

## 7. 地图加载流程
创建配置 → 生成房间图 → 计算位置 → 实例化房间 → 创建连接 → 玩家传送

## 8. 注意事项
- 房间尺寸建议：5x5 ~ 20x20瓦片
- 出口必须紧贴房间边界
- 必须验证连通性和Boss可达性
- 使用Tilemap优化渲染性能
- 预制体应使用GPU Instancing
