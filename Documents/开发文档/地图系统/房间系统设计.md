# 瓦片房间系统设计方案

## 一、系统概述

### 1.1 设计目标
构建一套基于预制瓦片房间的程序化地图生成系统，支持人工编辑房间内容，随机分支排列，最终汇集于Boss房间。

### 1.2 核心概念
- **房间(Room)**: 由瓦片组成的独立场景单元
- **出口(Exit)**: 房间的连接点，决定房间如何串联
- **房间模板(RoomTemplate)**: 可复用的房间预制体
- **路径(Path)**: 从起点到Boss的路线
- **地图(Map)**: 所有房间和连接的集合

## 四、地图生成算法

### 4.1 总体流程

```
1. 初始化随机种子
2. 创建起点房间和终点Boss房间
3. 规划主路径（连接起点和终点）
4. 在主路径上添加分支路径
5. 建立分支之间的横向连接，使不同路径连通
6. 在路径上插入特殊房间（精英、休息、商店、宝箱）
7. 验证路径连通性
8. 计算房间在地图中的物理位置
9. 生成走廊/连接物
10. 实例化房间预制体
```

### 4.2 房间图生成算法 (RoomGraphGenerator)

**职责**：
- 根据配置生成房间图结构
- 管理多条主路径的生成
- 处理分支房间的添加
- 建立路径间的横向连接

**关键方法**：

| 方法名 | 说明 |
|--------|------|
| Generate(MapGenerationConfig) | 入口方法，生成完整地图 |
| CreateStartRoom() | 创建起始房间 |
| CreateBossRoom() | 创建Boss房间 |
| GenerateMainPaths(start, end) | 生成多条主路径 |
| AddBranchesToPath(path) | 在主路径上添加分支 |
| ConnectPathsHorizontally() | 建立横向连接 |
| InsertSpecialRooms() | 插入特殊房间 |
| CalculateRoomPositions() | 计算房间物理位置 |

**多路径支持**：
- 支持生成2-3条主路径
- 每条路径独立但通过横向连接互通
- 分支概率：30%

### 4.3 房间放置算法 (RoomPlacer)

**常量**：
- CELL_SIZE: 每个房间占用的网格单元（20）

**关键方法**：

| 方法名 | 说明 |
|--------|------|
| PlaceRooms(GeneratedMap) | 入口方法，放置所有房间 |
| PlaceRoom(room, gridPos) | 放置单个房间 |
| PlaceRemainingRooms(map) | 按连接关系放置剩余房间 |
| CalculateNextPosition(room, connection) | 计算下一个房间位置 |

**防重叠策略**：
- 使用Dictionary记录已占用格子
- 房间周围1格范围内标记为占用
- BFS/Dijkstra计算最优位置

## 六、工作流程

### 6.1 制作房间流程

```
1. 创建RoomTemplate资源
   └── 右键 -> Create -> Map -> RoomTemplate

2. 打开RoomEditor编辑房间
   └── Tools -> Map -> Room Editor

3. 设置房间属性
   ├── 选择房间类型
   ├── 设置难度等级
   └── 配置宽高

4. 绘制瓦片
   ├── 选择瓦片调色板
   ├── 使用画笔工具绘制
   └── 使用橡皮擦删除

5. 设置出口
   ├── 点击E切换到出口模式
   ├── 点击边界位置添加出口
   └── 设置出口方向和类型

6. 保存房间
   └── 点击Save按钮
```

### 6.2 创建地图配置

```
1. 创建MapGenerationConfig
   └── 右键 -> Create -> Map -> GenerationConfig

2. 配置参数
   ├── 设置路径长度范围
   ├── 配置各类房间数量
   └── 拖入可用房间模板

3. 设置特殊房间
   ├── 拖入起始房间模板
   └── 拖入Boss房间模板

4. 测试生成
   └── Tools -> Map -> Map Test
```

### 6.3 运行时地图加载

|--------|------|
| GenerateMap() | 生成地图 |
| LoadAllRooms() | 实例化所有房间 |

## 七、注意事项

### 7.1 房间设计规范

- 房间尺寸建议：最小5x5，最大20x20瓦片
- 出口位置必须紧贴房间边界
- 同一房间至少2个出口（入口+出口）
- Boss房间只能有1个入口
- 起始房间只能有1个出口

### 7.2 性能优化

- 房间预制体应使用GPU Instancing
- 不活跃的房间可以延迟加载
- 瓦片应使用Tilemap而不是单独GameObject
- 地图数据应在场景加载前预加载

### 7.3 数据校验

- 地图生成后必须验证连通性
- 检查是否有孤立房间
- 验证Boss房间可达性
- 确保没有循环死路
