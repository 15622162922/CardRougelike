# 资源系统开发文档

## 1. 系统概述
资源系统负责游戏资源的加载、管理和卸载，支持多种加载模式。

## 2. 加载模式
- AssetBundle模式 - 打包后使用，支持热更新
- AssetDatabase模式 - Editor开发模式下使用
- ResourceManager - 通用资源管理

## 3. LoadManager架构
- AssetBundleLoader - AssetBundle加载
- AssetDatabaseLoader - Editor模式加载
- ResourceManager - 通用资源管理

## 4. 资源加载流程
请求加载 → 查找资源 → 加载资源 → 返回资源 → 缓存管理

## 5. 对象池系统
- ObjectPoolManager - 对象池管理器
- 对象获取/归还流程
- 对象回收机制
- 池化对象生命周期

## 6. 资源卸载
- 引用计数机制
- 资源卸载策略
- 内存管理

## 7. 注意事项
- 资源路径规范
- 依赖关系处理
- 内存泄漏防护
