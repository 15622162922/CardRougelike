# 配置系统开发文档

## 1. 系统概述
配置系统管理游戏的所有配置数据，包括Excel配置表和ScriptableObject。

## 2. Excel配置表

- 字段类型定义

- Config_TileDataConfig - 瓦片配置
- Config_TestConfig - 测试配置

## 3. ScriptableObject
- 运行时配置管理
- 创建与编辑流程
- 数据持久化

## 4. ConfigManager
- 配置加载流程
- 配置获取接口
- 配置缓存机制
- 热重载支持

## 5. 配置使用流程
定义配置表 → 生成代码 → 加载配置 → 获取数据
