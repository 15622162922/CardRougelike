# 战斗系统设计方案

## 一、系统概述

### 1.1 设计目标
构建一套快节奏的卡牌战斗系统，通过动态费用机制、自动普攻、和卡牌效果加成系统，实现流畅的战斗体验。

### 1.2 核心概念
- **职业(Class)** - 决定角色基础属性、可用卡组
- **普攻(NormalAttack)** - 自动触发的近战扫击
- **卡牌(Card)** - 消耗能量释放的技能
- **费用(Energy)** - 随时间回复的资源
- **Buff** - 属性加成系统

## 三、普通攻击系统

### 3.1 触发机制

**触发条件**：
- 范围内存在可攻击目标（敌人、可破坏物）
- 当前未处于冷却中
- 角色处于非受控状态（不受冰冻、眩晕等）

**检测方式**：
- 以角色为中心，半径为AttackRange的圆形区域检测
- 每帧检测或定时检测（每0.1秒）

### 3.2 攻击流程

```
触发检测
    │
    ├── 1. 扫描范围内目标
    │       └── FindTargetsInRange(AttackRange)
    │
    ├── 2. 选择攻击目标
    │       └── Priority: 最近 > 最低血量 > 随机
    │
    ├── 3. 面向目标
    │       └── transform.LookAt(target)
    │
    ├── 4. 播放攻击动画
    │       └── AnimComp.PlayAttackAnim(AttackAnim)
    │
    ├── 5. 触发伤害判定
    │       └── CalculateDamage() -> ApplyDamage()
    │
    ├── 6. 进入冷却
    │       └── StartCooldown(AttackInterval)
    │
    └── 结束
```

### 3.3 扫击攻击

**攻击范围**：
- 扇形区域（可配置角度，默认360度全方位）
- 半径等于角色AttackRange

**伤害计算**：
```
FinalDamage = BaseAttack * (1 + AttackBuff%) * SkillBonus%
```

**攻击属性**：

| 属性 | 说明 |
|------|------|
| AttackRange | 攻击范围半径 |
| AttackAngle | 扫击角度（360为全方位） |
| AttackInterval | 冷却时间 |
| AttackDelay | 攻击延迟（动画播放后多久判定） |

### 3.4 职业攻击差异

| 职业 | 攻击形态 | 特效 |
|------|----------|------|
| Warrior | 全力挥砍（360度） | 无特殊效果 |
| Mage | 法术弹幕（远程） | 发射魔法弹 |
| Rogue | 快速刺击（扇形45度） | 可触发中毒 |

## 四、卡牌系统

### 4.1 单位时间机制

**定义**：一个固定时间周期，用于同步能量回复和抽卡

**参数配置**：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| UnitTime | 3秒 | 标准周期 |
| EnergyPerUnit | 1 | 每周期回复能量 |
| CardsPerUnit | 1 | 每周期抽卡数量 |

**计时流程**：
```
每帧更新
    │
    ├── 累计 elapsedTime
    │
    ├── if elapsedTime >= UnitTime:
    │       ├── Energy += EnergyPerUnit (不超过上限)
    │       ├── DrawCard(CardsPerUnit)
    │       └── elapsedTime -= UnitTime
    │
    └── 继续
```

### 4.2 能量系统

**能量池**：
- 最大值：受职业和Buff影响
- 当前值：使用时减少，随时间恢复

**回复规则**：
- 每隔UnitTime回复一点能量
- 能量最大不超过MaxEnergy
- 战斗外不回复能量

**能量数据结构**：

| 字段 | 类型 | 说明 |
|------|------|------|
| Current | int | 当前能量 |
| Max | int | 最大能量 |
| RegenRate | float | 回复率 |
| UnitTime | float | 单位时间周期 |

### 4.3 卡牌数据结构

**CardData**：

| 字段 | 类型 | 说明 |
|------|------|------|
| CardId | string | 卡牌唯一ID |
| CardName | string | 卡牌名称 |
| CardType | CardType | 卡牌类型 |
| Cost | int | 能量消耗 |
| Description | string | 描述文本 |
| Icon | Sprite | 卡牌图标 |
| TargetType | TargetType | 目标类型 |
| Effect | CardEffect | 效果配置 |
| Rarity | CardRarity | 稀有度 |
| ClassLimit | ClassType | 可用职业限制 |

**CardType 枚举**：

| 类型 | 说明 |
|------|------|
| Attack | 攻击牌 |
| Defense | 防御牌 |
| Skill | 技能牌 |
| Power | 能力牌 |

**TargetType 枚举**：

| 类型 | 说明 |
|------|------|
| None | 无目标（释放时无需选择） |
| Enemy | 敌方目标 |
| Ally | 友方目标 |
| Self | 自身目标 |
| Position | 位置目标（地面释放） |

**CardRarity 枚举**：

| 稀有度 | 颜色 | 概率权重 |
|--------|------|----------|
| Common | 白色 | 60% |
| Uncommon | 绿色 | 30% |
| Rare | 蓝色 | 8% |
| Legendary | 橙色 | 2% |

### 4.4 卡牌效果系统

**CardEffect 基类**：

| 字段 | 类型 | 说明 |
|------|------|------|
| EffectId | string | 效果ID |
| EffectType | EffectType | 效果类型 |
| BaseValue | int/float | 基础数值 |
| BuffTags | List<string> | 关联的Buff标签 |

**EffectType 枚举**：

| 类型 | 参数 | 说明 |
|------|------|------|
| Damage | Value, Times | 造成伤害，可多次 |
| Heal | Value | 治疗 |
| DrawCard | Count | 抽牌 |
| GainEnergy | Value | 获得能量 |
| ApplyBuff | BuffId, Duration | 施加Buff |
| RemoveBuff | BuffId | 移除Buff |
| Summon | UnitId | 召唤单位 |
| Dash | Distance | 位移 |
| AreaDamage | Radius, Value | 范围伤害 |

**效果公式**：
```
FinalValue = BaseValue * (1 + CardEffectBuff%) * RoleBuff%
```

### 4.5 卡牌使用流程

**目标导向卡牌（需选择目标）**：

```
拖拽卡牌出卡组
    │
    ├── 显示释放区域预览
    │
    ├── 范围内显示有效目标
    │
    ├── 拖动到目标附近
    │
    ├── 松开卡牌
    │       ├── 检查能量是否足够
    │       ├── 检查目标是否有效
    │       └── 播放释放动画
    │
    ├── 消耗能量
    │       └── Energy -= Card.Cost
    │
    ├── 执行卡牌效果
    │       └── Effect.Apply(source, target)
    │
    └── 卡牌进入弃牌堆
```

**无目标卡牌（直接释放）**：

```
拖拽卡牌出卡组
    │
    ├── 检测能量是否足够
    │
    ├── 松开卡牌
    │       └── 播放释放动画
    │
    ├── 消耗能量
    │
    ├── 执行卡牌效果
    │
    └── 卡牌进入弃牌堆
```

## 五、Buff系统

### 5.1 Buff收集器

**位置**：集成在 RoleAttrComponent 中

**职责**：
- 管理角色当前所有Buff
- 提供Buff加成计算接口
- 处理Buff的添加、移除、计时

### 5.2 Buff数据结构

**BuffData**：

| 字段 | 类型 | 说明 |
|------|------|------|
| BuffId | string | Buff唯一ID |
| BuffName | string | Buff名称 |
| Tag | string | Buff标签（用于效果加成） |
| Duration | float | 持续时间（秒） |
| Value | float | 数值 |
| Stacks | int | 层数 |
| MaxStacks | int | 最大层数 |
| IsDebuff | bool | 是否为debuff |
| Source | string | 来源（卡牌ID/技能ID） |

### 5.3 Buff标签系统

**常用标签**：

| 标签 | 说明 |
|------|------|
| ATK | 攻击力加成 |
| DEF | 防御力加成 |
| SPD | 速度加成 |
| CRIT | 暴击率加成 |
| LIFE | 生命加成 |
| ENERGY | 能量加成 |
| POISON | 中毒效果 |
| BURN | 燃烧效果 |
| FROZEN | 冰冻效果 |

### 5.4 加成计算

**Buff计算优先级**：
1. 基础属性
2. 永久Buff加成（装备、天赋）
3. 临时Buff加成（卡牌、技能）
4. 叠加层数乘法

**加成公式**：
```
FinalAttack = BaseAttack * (1 + ATK_Bonus%) * (1 + CardBonus%)
```

**多标签加成**：
```
TotalBonus% = Sum(Tag_Bonus%)
```

### 5.5 Buff效果类型

| 类型 | 说明 |
|------|------|
| StatBoost | 属性提升（攻击+10%） |
| StatResist | 属性抗性（受到伤害-5%） |
| DOT | 持续伤害（每回合造成毒伤） |
| HOT | 持续治疗（每回合恢复生命） |
| CrowdControl | 控制效果（眩晕、冰冻） |
| Special | 特殊效果（伤害反弹、闪避） |

## 八、战斗流程总览

```
游戏开始
    │
    ├── 角色初始化
    │       ├── 加载职业配置
    │       ├── 初始化属性
    │       ├── 创建初始卡组
    │       └── 初始抽牌
    │
    ├── 进入战斗
    │       │
    │       ├── 每UnitTime循环
    │       │       ├── 回复1能量
    │       │       └── 抽1张牌
    │       │
    │       ├── 普攻触发检测
    │       │       └── 范围内有敌人 -> 自动普攻
    │       │
    │       ├── 玩家操作
    │       │       ├── 拖拽卡牌
    │       │       ├── 选择目标（如需）
    │       │       └── 释放卡牌
    │       │
    │       └── BuffTick更新
    │               └── 每帧更新持续时间
    │
    ├── 战斗结束判定
    │       ├── 玩家死亡 -> EndGame(PlayerDied)
    │       └── Boss死亡 -> EndGame(BossDefeated)
    │
    └── 结算
            ├── 同步数据
            ├── 成就检测
            └── 解锁检测
```

## 九、注意事项

### 9.1 卡牌平衡
- 高费用卡牌应有更强效果
- 零费用卡牌应有限制（冷却或数量）
- 同类卡牌应有差异化定位

### 9.2 Buff管理
- Buff叠加应有上限
- 负面Buff应有驱散手段
- Buff图标应有清晰区分

### 9.3 性能考虑
- 范围内目标检测使用空间分区
- Buff列表使用字典优化查找
- 卡牌效果计算应批量处理

### 9.4 扩展性
- 卡牌效果使用职责链模式便于扩展
- 新职业只需配置数据无需写代码
- Buff系统支持自定义标签
