# 游戏流程管理器设计方案

## 一、系统概述

### 1.1 设计目标
管理一场完整游戏的生命周期，包括游戏启动、进程控制、数据记录、游戏结束及结算。提供统一的游戏状态管理和数据收集接口。

### 1.2 核心概念
- **Game** - 游戏主控制器，管理整场游戏流程
- **GameState** - 游戏状态枚举
- **GameDataCollector** - 数据收集器，记录游戏过程中的各类统计
- **GameSummary** - 结算数据，包含本局游戏的总结信息

## 二、游戏状态机

### 2.1 GameState 枚举

| 状态 | 说明 | 可转换到 |
|------|------|---------|
| None | 初始状态 | Loading |
| Loading | 资源加载中 | Playing |
| Playing | 游戏进行中 | Paused, Summary |
| Paused | 游戏暂停 | Playing |
| Summary | 结算阶段 | None |

### 2.2 状态转换图

```
None -> Loading -> Playing -> Summary -> None
                    |
                    v
                 Paused
                    |
                    v

```

## 三、Game类设计

### 3.1 类职责

**Game** 是游戏进程的核心类，负责：
- 管理游戏生命周期（启动、运行、结束）
- 维护游戏核心对象引用
- 协调各子系统初始化
- 触发游戏状态转换

### 3.2 核心属性

| 属性 | 类型 | 说明 |
|------|------|------|
| Instance | static Game | 单例实例 |
| CurrentState | GameState | 当前游戏状态 |
| Seed | int | 本局游戏随机种子 |
| MapData | GeneratedMap | 当前地图数据 |
| Player | Role | 玩家角色 |
| CurrentRoom | GeneratedRoom | 当前所在房间 |
| DataCollector | GameDataCollector | 数据收集器 |
| Summary | GameSummary | 结算数据 |

### 3.3 关键方法

**生命周期管理**：

| 方法名 | 说明 |
|--------|------|
| NewGame() | 开始一场新游戏 |
| LoadGame(saveData) | 加载存档继续游戏 |
| PauseGame() | 暂停游戏 |
| ResumeGame() | 继续游戏 |
| EndGame(EndCondition) | 结束游戏 |
| ResetGame() | 重置游戏 |

**房间管理**：

| 方法名 | 说明 |
|--------|------|
| LoadMap(seed) | 根据种子生成地图 |
| EnterRoom(roomId) | 进入指定房间 |
| ClearCurrentRoom() | 清理当前房间怪物 |

**数据记录**：

| 方法名 | 说明 |
|--------|------|
| RecordDamage(source, target, value) | 记录伤害 |
| RecordCardUsed(cardId) | 记录卡牌使用 |
| RecordEnemyKilled(enemyType) | 记录击杀 |
| RecordRoomEntered(roomType) | 记录房间进入 |

### 3.4 结束条件 (EndCondition)

| 条件 | 说明 |
|------|------|
| PlayerDied | 玩家死亡 |
| BossDefeated | 击败最终Boss |
| Quit | 主动退出 |
| Error | 异常结束 |

## 四、游戏启动流程

### 4.1 启动序列图

```
NewGame()
    │
    ├── 1. 生成随机种子
    │       └── Seed = System.Random.Next()
    │
    ├── 2. 创建数据收集器
    │       └── DataCollector = new GameDataCollector(Seed)
    │
    ├── 3. 加载地图
    │       └── MapData = RoomGraphGenerator.Generate(Seed)
    │
    ├── 4. 创建玩家角色
    │       ├── 实例化Player预制体
    │       ├── 初始化属性组件
    │       └── 初始化动画组件
    │
    ├── 5. 初始化卡牌系统
    │       ├── 创建初始手牌
    │       └── 洗牌
    │
    ├── 6. 创建怪物管理器
    │       └── EnemyManager = new EnemyManager()
    │
    ├── 7. 通知UI显示
    │       └── UIManager.ShowGameUI()
    │
    ├── 8. 状态切换
    │       └── CurrentState = GameState.Playing
    │
    └── 9. 触发GameStart事件
```

### 4.2 初始化参数配置

| 配置项 | 说明 |
|--------|------|
| 随机种子 | 用于地图生成、掉落判定等 |
| 初始卡组 | 玩家初始携带的卡牌列表 |
| 初始属性 | 玩家初始生命值、攻击力等 |
| 可用房间模板 | 地图生成所需房间资源 |

## 五、游戏结束流程

### 5.1 结束判定

| 触发条件 | 检测方式 |
|----------|----------|
| 玩家死亡 | Player.AttrComp.CurrentHp <= 0 |
| 击败Boss | CurrentRoom.RoomType == Boss && 所有敌人死亡 |
| 主动退出 | 用户点击退出按钮 |

### 5.2 结束序列图

```
EndGame(EndCondition)
    │
    ├── 1. 状态切换
    │       └── CurrentState = Summary
    │
    ├── 2. 停止游戏逻辑
    │       ├── 停止玩家输入
    │       ├── 停止敌人AI
    │       └── 暂停所有计时器
    │
    ├── 3. 清理当前房间
    │       └── ClearCurrentRoom()
    │
    ├── 4. 生成结算数据
    │       └── Summary = GenerateSummary()
    │
    ├── 5. 同步数据到外部收集器
    │       └── SyncToGlobalCollector()
    │
    ├── 6. 触发成就检测
    │       └── AchievementSystem.Check(Summary)
    │
    ├── 7. 解锁检测
    │       ├── CheckCardUnlocks()
    │       └── CheckCosmetisUnlocks()
    │
    ├── 8. 计算升级经验
    │       └── CalculateProgression()
    │
    ├── 9. 显示结算界面
    │       └── UIManager.ShowSummary(Summary)
    │
    └── 10. 触发GameEnd事件
```

## 十、注意事项

### 10.1 单例管理
- Game类采用单例模式，确保全局唯一
- 不可通过new创建，必须通过Game.NewGame()启动

### 10.2 状态转换规则
- 只有Playing状态才能转换到Summary
- Summary状态只能转换到None（重置）
- 状态转换必须通过Game类方法，不允许外部直接修改

### 10.3 数据完整性
- 游戏结束后，所有DataCollector数据必须同步到全局
- 同步前应进行数据校验
- 存档保存应在同步之后

### 10.4 事件通知
- 游戏状态转换应通过事件通知相关系统
- 建议使用UnityEvent或自定义事件系统
