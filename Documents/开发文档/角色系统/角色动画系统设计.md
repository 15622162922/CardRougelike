# 角色动画系统设计方案

## 一、系统概述

### 1.1 设计目标
构建一套基于Animator的上下半身动画分离系统，支持角色在播放移动动画的过程中执行攻击动画，实现流畅的动作组合效果。

### 1.2 核心概念
- **AnimatorController** - Unity动画控制器
- **AvatarMask** - 化身遮罩，用于区分上下半身动画层
- **AnimationLayer** - 动画层级，分为BaseLayer、UpperBodyLayer
- **AnimationSlot** - 动画槽位，管理不同类型的动画播放

---

## 二、架构设计

### 2.1 层级架构

```
AnimatorController
├── Base Layer (下半身)     - 移动、待机、受击
│   ├── State: Idle
│   ├── State: Move
│   └── State: Hit
│
└── Upper Body Layer (上半身) - 攻击、技能
    ├── State: Attack
    ├── State: Skill
    └── State: UpperIdle
```

### 2.2 组件结构

```
Role
├── RoleAnimComponent        - 动画控制组件（新增）
├── RoleMoveComponent        - 移动控制组件
├── RoleAttackComponent      - 攻击控制组件
└── RoleAttrComponent        - 属性控制组件
```

---

## 三、核心类设计

### 3.1 RoleAnimComponent - 动画控制组件

**职责**：
- 管理角色的动画状态机
- 实现上下半身动画层分离
- 提供动画播放接口给其他组件调用

**关键方法**：

| 方法名 | 说明 | 调用者 |
|--------|------|--------|
| Initialize(Role owner) | 初始化动画组件 | Role |
| PlayAnim(string, AnimLayer, int, bool) | 播放指定动画 | 内部/外部 |
| PlayMoveAnim(float) | 播放移动动画 | MoveComp |
| PlayIdleAnim() | 播放待机动画 | MoveComp |
| PlayAttackAnim(string) | 播放攻击动画 | AttackComp |
| PlayHitAnim() | 播放受击动画 | AttrComp |
| PlayDeadAnim() | 播放死亡动画 | AttrComp |
| SetMoveSpeed(float) | 设置移动速度参数 | MoveComp |
| IsAnimPlaying(string, AnimLayer) | 检查动画是否正在播放 | 外部系统 |
| StopAllAnim() | 停止所有动画 | 外部系统 |

**动画层索引**：
- Base Layer: 索引 0
- Upper Body Layer: 索引 1

**动画参数**：
- MoveSpeed: 移动速度
- IsMoving: 是否移动中
- Attack: 攻击触发
- Hit: 受击触发
- Dead: 死亡触发

### 3.2 动画请求结构

**AnimRequest**:
| 字段 | 类型 | 说明 |
|------|------|------|
| AnimName | string | 动画名称 |
| Layer | AnimLayer | 动画层类型 |
| Priority | int | 优先级（数值越高越优先） |
| CrossFade | bool | 是否淡入淡出 |
| CrossFadeDuration | float | 动画混合时间 |

**AnimLayer 枚举**:
| 值 | 说明 |
|----|------|
| Base | 基础层（下半身：移动、待机） |
| UpperBody | 上半身层（攻击、技能） |

**AnimType 常量**:
| 常量 | 说明 |
|------|------|
| IDLE | 待机动画 |
| MOVE | 移动动画 |
| ATTACK_1, ATTACK_2, ATTACK_3 | 普通攻击动画 |
| SKILL_1, SKILL_2, SKILL_3 | 技能动画 |
| HIT | 受击动画 |
| DEAD | 死亡动画 |

## 四、AnimatorController配置

### 4.1 动画层设置

```
Layer 1: UpperBody (Weight: 0)
  - AvatarMask: UpperBody
  - Blending: Override
  - State: Attack, Skill, Empty
   
Layer 0: Base (Weight: 1)
  - AvatarMask: None
  - Blending: Override
  - State: Idle, Move, Hit, Dead
```

### 4.2 AvatarMask配置

**下半身包含部位**：
- LeftFoot
- RightFoot

**上半身包含部位**：
- Head
- Body
- LeftHand
- RightHand

### 4.3 动画状态机转换规则

**Base Layer (下身)**:
- Idle ↔ Move (相互转换，条件: IsMoving)
- AnyState → Hit (转换条件: OnHit)
- AnyState → Dead (转换条件: OnDead)

**UpperBody Layer (上身)**:
- Empty → Attack (转换条件: OnAttack)
- Empty → Skill (转换条件: OnSkill)
- Attack → Empty (转换条件: AttackEnded)
- Skill → Empty (转换条件: SkillEnded)

## 五、组件调用接口

### 5.1 RoleMoveComponent调用动画

| 方法 | 调用 | 说明 |
|------|------|------|
| MoveTo(Vector3) | PlayMoveAnim() | 播放移动动画 |
| StopMove() | PlayIdleAnim() | 播放待机动画 |

### 5.2 RoleAttackComponent调用动画

| 方法 | 调用 | 说明 |
|------|------|------|
| Attack(string) | PlayAttackAnim() | 播放攻击动画，不中断移动动画 |

### 5.3 RoleAttrComponent调用动画

| 方法 | 调用 | 说明 |
|------|------|------|
| TakeDamage(int) | PlayHitAnim() | 播放受击动画 |
| TakeDamage(int) 导致死亡 | PlayDeadAnim() | 播放死亡动画 |

## 六、Role类集成

### 6.1 Role类结构

**组件引用**：
- AnimComp: RoleAnimComponent
- MoveComp: RoleMoveComponent
- AttackComp: RoleAttackComponent
- AttrComp: RoleAttrComponent

**公开接口**：
- PlayAnimation(string, AnimLayer): 播放动画
- PlayMoveAnim(float): 播放移动动画
- PlayAttackAnim(string): 播放攻击动画

## 七、使用示例

### 7.1 玩家控制

```
移动: W键 -> MoveComp.MoveTo() + PlayMoveAnim()
攻击: J键 -> AttackComp.Attack() -> 移动动画不被中断
```

### 7.2 移动中攻击

```
1. 角色播放移动动画（Base Layer）
2. 发起攻击，播放攻击动画（UpperBody Layer）
3. 上下半身同时播放不同动画
4. 攻击动画结束后自动恢复
```

## 八、注意事项

### 8.1 AvatarMask设置
- 确保角色模型是Humanoid类型
- AvatarMask的部位设置必须与动画模型匹配
- 下半身通常包含：LeftFoot, RightFoot
- 上半身通常包含：Head, Body, LeftHand, RightHand

### 8.2 动画层权重
- Base Layer默认权重为1
- UpperBody Layer默认权重为0
- 攻击动画播放时将UpperBody权重渐变到1
- 攻击动画结束后将UpperBody权重渐变回0

### 8.3 动画事件
- 在动画中添加Animation Event用于精确触发伤害判定
- 建议在动画50%进度时触发伤害
- 避免在动画开始时立即触发伤害

### 8.4 性能优化
- 避免同时播放过多动画层
- 使用AnimatorParameters而非直接访问State
- 动画状态机层级不宜过深
